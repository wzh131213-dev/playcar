# PolyTrack 写实版（网页）

玩法、物理、赛道、成绩全部与原版相同，只替换了画面渲染。

## 运行
- macOS：双击 `start.command`；Windows：双击 `start.bat`；或 `python3 serve.py` 后打开 http://localhost:8080
- 部署：整个文件夹作为静态站点上传即可。

## 切换画面
- 写实版（默认）：http://localhost:8080/
- 原版画面：http://localhost:8080/?classic

## 画面改动（全部在 realistic.js，约 200 行，可读可改）
- 线性光照管线 + sRGB 输出 + Khronos PBR Neutral 色调映射
- 程序化 HDR 天空 → 环境光照与车漆/金属/轮毂反射
- 暖色太阳 + 冷色天光，软阴影，大气雾（远山朦胧）
- 沥青颗粒、草地斑驳（暗绿↔枯黄）、陡坡自动露出土石（程序化，无外部贴图）
- 车身/地形法线平滑（保留车身折线），车漆清漆感、橡胶/金属材质参数
- 轻微暗角

## 调参
realistic.js 顶部 CFG：exposure（曝光）、sun（日光）、hemi（天光）、env（环境反射）、fogNear/fogFar（雾）。

## 已知限制
- 模型仍是原版低多边形（车身、山体轮廓、树木），写实的是光照/材质/大气，不是几何。想要真正的高模需要替换 models/*.glb。
- 地表细节为逐像素噪声，核显/手机上帧率会比原版低；若卡，可用 `?classic`，或降低阴影质量（游戏设置里）。
- 在线排行榜同上一版说明：取决于官方服务器是否接受你的域名。
